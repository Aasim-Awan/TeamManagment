# TeamFund Manager

A comprehensive Android application for managing team funds, expenses, contributions, and match records. Perfect for sports teams, social clubs, or any group that manages collective finances.

## Key Features

- **Team Management**: Create and manage multiple teams with custom logos and sports types.
- **Player Roster**: Maintain an active list of players with roles and financial summaries.
- **Match Tracking**: Record match details, opponents, results, and associated expenses.
- **Expense Logging**: Track team expenses with category-wise breakdown and split-cost support.
- **Contribution Management**: Record player contributions and subscriptions to the team fund.
- **Settlement Tracking**: Manage payments between players and the team fund.
- **Financial Reports**: Get insights into team balance, player debts, and expense distribution.
- **CSV Export**: Export contributions and expenses to CSV for external record-keeping.

## Tech Stack

- **Kotlin**: Primary programming language.
- **Jetpack Compose**: Modern UI toolkit for building native Android interfaces.
- **Room Database**: For local data persistence and offline support.
- **DataStore**: For lightweight user preferences.
- **Flow & Coroutines**: For asynchronous programming and reactive UI updates.
- **Material 3**: Latest Android design system.

## Getting Started

### Prerequisites

- [Android Studio Ladybug](https://developer.android.com/studio) or newer.
- Android SDK 24 (Nougat) or higher.

### Installation

1. Clone or download the repository.
2. Open the project in Android Studio.
3. Sync project with Gradle files.
4. Run the app on an emulator or a physical device.

## Package Information

- **Package Name**: `com.teamfund.manager`
- **Application ID**: `com.teamfund.manager`

## Exporting Data

You can export financial data to CSV format from the **Reports** screen. Look for the "Export" icons in the Contributions and Expenses sections.
